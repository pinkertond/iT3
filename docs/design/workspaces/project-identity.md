# A workspace shares the project's identity

A project is identified by its environment and native project ID. Assigning it to a workspace preserves both identifiers. Opening it from Everything or from its named workspace resolves to the same project and the same chats. Each client chooses which workspace it is viewing. The host persists the project's placement.
